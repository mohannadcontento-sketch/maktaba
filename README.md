# 📚 مكتبة — Maktaba

قارئ كتب احترافي لملفات **EPUB** و **PDF** بواجهة عربية أولاً (RTL)، مبني بتقنيات الويب ويعمل على Windows.

---

## ✨ المزايا

### 🗂️ المكتبة
- استيراد الكتب بالسحب والإفلات، أو عبر منتقي الملفات، أو مسح مجلد كامل دفعة واحدة.
- دعم فتح الملفات مباشرة عبر «فتح باستخدام» مع ربط أنواع `pdf` / `epub`.
- بطاقات كتب مع استخراج الأغلفة والبيانات الوصفية تلقائيًا (العنوان، المؤلف، الناشر، عدد الصفحات…).
- تنظيم بالمفضلة ⭐ والتقييم والحالة (جديد / قيد القراءة / مكتمل) والوسوم الملونة والمجموعات.
- تعديل البيانات الوصفية يدويًا لكل كتاب.

### 📖 القارئ
- قارئ **EPUB** مبني على epub.js وقارئ **PDF** مبني على pdf.js — بمحرك عرض موحّد.
- سمات قراءة: نهاري / ورقي (Sepia) / ليلي، مع تحكم بحجم الخط ونمط التدفق (تمرير/صفحات).
- تحديد النص للتظليل والتسطير وكتابة الملاحظات، مع نافذة منبثقة سريعة.
- علامات مرجعية، لوحات جانبية (الفهرس، العلامات المرجعية، التعليقات).
- متابعة موضع القراءة واستئنافه تلقائيًا عند آخر موقع.
- وضع القراءة العمياء (Zen) عبر F11، ودعم الطباعة.

### 📊 الإحصائيات
- زمن القراءة الفعلي بجلسات تتبّع دقيقة، وعدد الصفحات المقروءة.
- سلسلة الأيام المتتالية (Streak) ورسم آخر 14 يومًا.
- أكثر الكتب قراءةً، وإجماليات التعليقات والعلامات المرجعية.

### ⚙️ الإعدادات والتجربة العامة
- واجهة ثنائية اللغة: **العربية** (افتراضي، RTL) والإنجليزية.
- سمة التطبيق: فاتحة / داكنة / حسب النظام.
- شريط عنوان مخصص متكامل مع نظام التشغيل، ونافذة واحدة تمنع التكرار.
- تخزين محلي بالكامل عبر SQLite — لا خوادم ولا حسابات.

## 🚀 التشغيل محليًا

```bash
# 1. تثبيت الاعتماديات (يعيد بناء الوحدات الأصلية تلقائيًا لـ Electron)
npm install

# 2. تشغيل وضع التطوير مع إعادة التحميل الساخن
npm run dev
```

### أوامر مساعدة

```bash
npm run typecheck        # فحص TypeScript (العملية الرئيسية + الواجهة)
npm run build            # بناء نسخة الإنتاج إلى out/
npm run dist             # بناء الإنتاج + المثبت (NSIS + Portable) إلى release/
npm run fixtures         # توليد كتب عينة للتجربة في samples/
```

> **ملاحظة:** أول عملية تغليف قد تستغرق وقتًا أطول لتنزيل أدوات NSIS.

## 📁 هيكل المشروع

```
src/
├── main/          # العملية الرئيسية: قاعدة البيانات، IPC، إدارة المكتبة، بروتوكول book://
├── preload/       # جسر آمن (contextIsolation) بين العمليتين
├── renderer/      # واجهة React: الصفحات والمكونات والمخازن والخطوط العربية
└── shared/        # الأنواع المشتركة بين العمليتين
build/             # موارد البناء (الأيقونات)
samples/           # كتب عينة للتجربة
scripts/           # سكربتات الأدوات (توليد العينات)
```

بيانات المستخدم (الكتب المستوردة، قاعدة البيانات، الأغلفة) تُخزَّن في مجلد بيانات التطبيق، ويمكن الوصول إليها من **الإعدادات ← التخزين ← فتح مجلد البيانات**.
