# تطبيق «مكتبة» — قارئ كتب احترافي لسطح المكتب (EPUB + PDF)

## نظرة عامة
تطبيق ديسكتوب احترافي لإدارة مكتبة الكتب وقراءتها، بواجهة عربية RTL أنيقة مع إمكانية التبديل للإنجليزية، يجمع بين قوة أكروبات في التعامل مع PDF وتجربة مون ريدر الغنية في القراءة الإلكترونية.

## التقنيات
- **Electron + React + TypeScript** عبر قالب `electron-vite` (Vite للعمليات الثلاث مع HMR)
- **pdf.js (pdfjs-dist)** لعرض PDF: طبقة نص، بحث، مصغرات، فهرس
- **epub.js** لعرض EPUB: ترقيم صفحات، سمات، مواقع CFI للتعليقات
- **better-sqlite3** لقاعدة بيانات المكتبة (كتب، تعليقات، علامات مرجعية، جلسات قراءة، إعدادات)
- **Tailwind CSS** + مكونات UI يدوية بنمط shadcn، **zustand** للحالة، **i18next** للغتين عربي/إنجليزي
- **electron-builder** لتوليد مثبّت NSIS + نسخة Portable لأجهزة Windows
- خطوط قراءة مدمجة محليًا: Amiri، Cairo، Tajawal، Noto Naskh + خطوط لاتينية

## هيكل المشروع
```
src/
├── main/            # عملية Electron الرئيسية
│   ├── index.ts         # إنشاء النوافذ والقائمة
│   ├── db.ts            # SQLite + هجرات الجداول
│   ├── library.ts       # استيراد الملفات، نسخها للتخزين، استخراج البيانات والأغلفة
│   └── ipc.ts           # قنوات IPC (استيراد، حذف، أغلفة، إحصائيات، طباعة…)
├── preload/index.ts # جسر contextBridge آمن
└── renderer/src/
    ├── components/
    │   ├── library/   # شبكة الأغلفة، القائمة، الشريط الجانبي، محرر البيانات
    │   ├── reader/    # PdfReader، EpubReader، الهيكل المشترك، طبقة التعليقات
    │   └── ui/        # أزرار، نوافذ حوارية، قوائم منسدلة…
    ├── stores/        # zustand (المكتبة، القارئ، الإعدادات)
    ├── i18n/          # ar.json / en.json
    └── pages/         # المكتبة، القارئ، الإحصائيات، الإعدادات
```

## قاعدة البيانات
جداول: `books` (عنوان، مؤلف، صيغة، مسار، غلاف، تقدم، آخر موقع، حالة قراءة، تقييم)، `tags` + `book_tags`، `collections` + `collection_books`، `annotations` (تمييز/تسطير/ملاحظة + لون + موقع CFI أو صفحة PDF)، `bookmarks`، `reading_sessions` (للإحصائيات)، `settings`. التعليقات تُحفظ كطبقة داخل التطبيق (حسب اختيارك).

## المزايا

### 📚 المكتبة
- استيراد بالسحب والإفلات أو منتقي ملفات أو مسح مجلد كامل (pdf/epub)
- استخراج تلقائي للبيانات الوصفية والغلاف (من OPF للـEPUB، ومن الصفحة الأولى للـPDF)
- عرض شبكة أغلفة / قائمة تفصيلية، فرز متعدد، تصفية (قيد القراءة/غير مقروء/منتهي/مفضل)
- رفوف ومجموعات مخصصة، وسوم ملونة، بحث فوري، صف «أكمل القراءة» بأشرطة تقدم
- تحرير البيانات يدويًا (عنوان، مؤلف، تقييم نجوم، وصف)، قائمة سياق كاملة لكل كتاب

### 📕 قارئ PDF (مستوى أكروبات)
- عرض متصل بتقنية الافتراضية (يرسم الصفحات المرئية فقط للأداء)
- تكبير/تصغير + ملاءمة العرض/الصفحة + Ctrl+عجلة الفأرة
- شريط جانبي: مصغرات، فهرس المستند، قائمة التعليقات، العلامات المرجعية
- تحديد النص والنسخ، البحث داخل المستند بإبراز كل النتائج وتنقل بينها
- أدوات تعليق: تمييز بخمس ألوان، تسطير، ملاحظات، مع لوحة إدارة وحذف وتعديل
- وضع ليلي (قلب الألوان)، تدوير، طباعة، ملء الشاشة، حفظ تلقائي لموضع القراءة واستئنافه

### 📗 قارئ EPUB (تجربة مون ريدر)
- وضع صفحات (أعمدة) أو تمرير مستمر
- سمات جاهزة: نهاري / ورقي Sepia / ليلي + سمة مخصصة بالألوان
- ضبط كامل للخط (نوع، حجم، تباعد أسطر، هوامش، محاذاة) مع الخطوط العربية المدمجة
- جدول محتويات تنقّلي، شريط تقدم بمواقع محسوبة + تقدير وقت القراءة المتبقي
- نفس نظام التعليقات (تمييز/تسطير/ملاحظة على أي نص عبر CFI) والعلامات المرجعية
- حفظ آخر موضع تلقائيًا واستئناف القراءة منه

### ⚙️ عام
- ثيم التطبيق (نهاري/ليلي/تلقائي) ولغة الواجهة (عربي/إنجليزي) وإعدادات قراءة افتراضية
- إحصائيات: وقت القراءة الكلي، سلسلة الأيام، عدد الكتب المنتهية، الوقت لكل كتاب
- اختصارات لوحة مفاتيح كاملة، فتح مجلد البيانات، نسخ احتياطي/تصدير التعليقات
- توليد أيقونة تطبيق احترافية (SVG → ICO/PNG)

## خطة التنفيذ (مراحل)
1. **الهيكل**: scaffold المشروع، Tailwind، i18n، التنقل بين الصفحات، الثيم الليلي، مكونات UI الأساسية
2. **طبقة البيانات**: SQLite + IPC + خط أنابيب الاستيراد (نسخ، بيانات وصفية، أغلفة)
3. **واجهة المكتبة** كاملة بشتيها عرضيها
4. **قارئ PDF الأساسي**: عرض، تنقل، تكبير، فهرس، مصغرات، بحث
5. **تعليقات PDF**: تمييز/تسطير/ملاحظات + علامات مرجعية + استئناف الموضع
6. **قارئ EPUB الأساسي**: عرض، سمات، طباعة حروف، تنقل، فهرس
7. **تعليقات EPUB** + علامات مرجعية + استئناف
8. **الإحصائيات والإعدادات** والاختصارات والتلميع
9. **التغليف**: أيقونة، إعدادات electron-builder، بناء المثبت، اختبار تشغيل، README
